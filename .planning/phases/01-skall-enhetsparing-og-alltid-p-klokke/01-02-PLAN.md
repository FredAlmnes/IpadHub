<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iPad PWA -> /api/pair/poll | Unauthenticated; holds only the pollSecret |
| iPad PWA -> /api/snapshot | Device cookie authenticates; returns private data in later phases |
| developer shell -> D1 (approve CLI) | Requires wrangler credentials for --remote |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07 | Spoofing | /api/pair/poll | mitigate | pollSecret is 256-bit, stored hashed; unknown/malformed secret returns the same {status:"expired"} (no oracle); approval only via admin or owner CLI |
| T-01-08 | Tampering | double cookie issuance race | mitigate | conditional UPDATE ... WHERE status='approved' RETURNING claims the request once; test 3 asserts single use |
| T-01-09 | Information disclosure | device token | mitigate | token only in HttpOnly Set-Cookie (SameSite=Lax, Secure on https), never in JSON or JS; only sha256 in D1 |
| T-01-10 | Spoofing | stolen/lost device | mitigate | revoked_at checked on every request; client drops cached snapshot data with removeQueries on 401 (test 8) |
| T-01-11 | Denial of service | false un-pair on outages/quota 429 | mitigate | only exact 401 triggers pairing; retry excludes UnpairedError only |
| T-01-12 | Tampering | SQL injection via approve CLI | mitigate | strict allow-list regexes reject quotes before SQL is built; execFileSync without shell |
| T-01-13 | Denial of service | D1 write quota from last-seen | mitigate | last_seen_at write at most every 5 min per device (test 9) |
</threat_model>
